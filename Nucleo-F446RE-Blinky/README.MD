# blinky

Blinks the on-board green LED (LD2) on the NUCLEO-F446RE every 1000 ms.

## Hardware

| Item | Detail |
|------|--------|
| Board | NUCLEO-F446RE (STM32F446RE) |
| LED | LD2, green, on pin **PA5** (driving the pin high turns it on) |
| Connection | USB cable to the ST-LINK port on the board |

## Tools

- STM32CubeIDE 2.2.0
- STM32CubeMX (standalone, used to configure pins and generate code)

## What it does

1. `MX_GPIO_Init()` (generated by CubeMX) configures PA5 as a push-pull output.
2. The main loop toggles the pin, then waits 1000 ms.

The code I added, inside the `USER CODE` markers in `Core/Src/main.c`:

```c
while (1)
{
  /* USER CODE BEGIN 3 */
  HAL_GPIO_TogglePin(LD2_GPIO_Port, LD2_Pin);
  HAL_Delay(1000);
}
/* USER CODE END 3 */
```

## CubeMX configuration

- Board: NUCLEO-F446RE
- PA5: `GPIO_Output`, user label `LD2`
- SYS -> Debug: Serial Wire
- Toolchain/IDE: STM32CubeIDE

## Build and run

1. In STM32CubeIDE: *File -> Import... -> General -> Existing Projects into Workspace*.
2. Select this folder and leave "Copy projects into workspace" unchecked.
3. Build (hammer icon), then Run.

The LED should blink twice per second.

## What I learned

- Where CubeMX-generated code ends and my code begins (`USER CODE BEGIN` / `USER CODE END`).
- Using `HAL_GPIO_TogglePin` and `HAL_Delay`.
- How label macros like `LD2_Pin` and `LD2_GPIO_Port` map to the physical pin.
- The two-app workflow in CubeIDE 2.x: CubeMX for configuration, CubeIDE for coding and debugging.
